# Journey mascot assets

The six drawings `ProgressMascot` renders, one per adherence state. They are
designer exports and are **not** generated by this repository.

## Required files

| File           | Adherence band | What it shows                     |
| -------------- | -------------- | --------------------------------- |
| `state-1.webp` | 0–10%          | The character at the start        |
| `state-2.webp` | 10–25%         | A first step taken                |
| `state-3.webp` | 25–45%         | Settled, standing                 |
| `state-4.webp` | 45–70%         | Confident, arms up                |
| `state-5.webp` | 70–90%         | Stronger, hands on hips           |
| `state-6.webp` | 90–100%        | Celebrating, arms raised          |

The names are produced by `MASCOT_ASSETS` in
`src/features/portal/mascot/assets.ts`. Renaming a file means editing that table
— nothing else in the app writes one of these paths.

## Export contract

The six are cross-faded into one another in place, so they have to be
interchangeable frames of the same character rather than six separate pictures:

- **Square canvas**, identical dimensions across all six. `MASCOT_SIZES.lg` is
  200px, so export at 400px square for 2× displays.
- **Transparent background.** The card paints its own surface and §16 forbids a
  visible box around the character.
- **Identical framing** — same ground line, same centre, same scale. The figure
  must not drift or resize between states, or the cross-fade reads as the
  character jumping rather than changing.
- **WebP.** These are flat-shaded figures on transparency, which is the case
  WebP compresses hardest; the same drawing as PNG is several times the bytes
  for no visible difference.

## Missing files

`ProgressMascot` hides any drawing whose file fails to load, per state, rather
than showing a broken-image glyph — so a partially delivered set degrades to an
empty square inside an otherwise working card. The percentage, the progress bar
and the encouragement beside it are unaffected, because none of them read the
image.
